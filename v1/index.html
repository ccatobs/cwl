The ccat: CWL namespace, contract v1

URI: https://ccatobs.github.io/cwl/v1#. Prefix: ccat:.

$namespaces:
  ccat: https://ccatobs.github.io/cwl/v1#

CWL treats the URI as an identifier. cwltool requests this page to check the hint class ccat:Contract. The rules are in contracts/v1.md of ccatobs/ccat-pipelines; this page defines the terms only.

Terms

ccat:Contract

Hint class, used under hints of a CommandLineTool. It names the contract version that the tool implements.

hints:
  ccat:Contract:
    version: 1

ccat:Contract field version

Integer. The contract version. For this namespace the value is 1. Registration and submit refuse an unsupported version.

ccat:role

Field of a CWL output. A DataProductType value of ops-db: science, qa_metric, plot, log, statistics or intermediate. It gives the product type of the output.

ccat:dims

Field of a CWL output. A map of dimension names to values that identify the product within the run. The result collector merges it over the dims of the run.

ccat:manifest

Field of a CWL File output. The value true marks the output as an output manifest that lists products static outputs cannot describe.

ccat:sink

Field of a CWL output. The form is {influx: <measurement>}. The output is a CSV time series that the result collector writes to InfluxDB. It is not a data product.

ccat:warnings

Field of an optional CWL output. The value true marks the output as a warning signal. When a completed run holds the output (not null), the run is completed with warnings. A null optional output without the mark is not a warning.
